- `styles.css` — responsive styling / design system
- `script.js` — mobile navigation + WhatsApp enquiry form
- `assets/` — favicon, brand monogram, visual-system artwork

## Images
The prototype uses one publicly indexed Estate Lookup / Homify image plus editorial Unsplash imagery for the new visual direction. Before production launch, replace these URLs with approved original Estate Lookup project photographs. This is important so the final portfolio represents only the firm's own work and avoids third-party image licensing issues.

Image URLs are kept directly in `styles.css` under `.hero-image-*` and `.image-*` for fast replacement.

## Hosting
No build step is required. Upload the folder to cPanel/Hostinger or deploy to Netlify, Vercel, GitHub Pages, etc.

The contact form intentionally opens WhatsApp with the enquiry details, so it works without a backend. Update the WhatsApp number in `index.html` and `script.js` if the preferred business number changes.

## Design direction
- Deep green / warm ivory / muted brass
- Editorial typography and large-image layouts
- Stronger premium positioning than the current site
- Clear conversion path: work → services → process → proof → consultation
- Mobile-first, but intentionally spacious on desktop
